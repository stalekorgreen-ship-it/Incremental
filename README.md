# ЛентаОС

Платная инкрементальная игра для ПК с детективной линией. Всё происходит внутри компьютера 1999 года: игрок строит рекомендательный алгоритм анонимной соцсети.

**Прототип. Репозиторий содержит спойлеры к сюжету** (`docs/`, `detective-SPOILER/`). Папку `detective-SPOILER/` автор игры не открывает: он хочет пройти расследование вслепую.

| Где | Что |
|---|---|
| `CLAUDE.md` | как работать с проектом (читать первым, если ты модель) |
| `docs/TZ.md` | техническое задание |
| `docs/DECISIONS.md` | решения, что отвергнуто, что не решено |
| `docs/ARCHITECTURE.md` | устройство кода, сборка, тесты |
| `docs/STATUS.md` | что готово, слабые места, что дальше |
| `docs/RESEARCH.md` | отзывы на похожие игры и выводы про веселье |
| `net3/` | лента и конструктор алгоритма (12 испытаний, 30 источников) |
| `pc99/` | компьютер 1999 года с браузером и сайтами, внутри него игра |
| `ed/topics.js` | тексты постов |
| `detective-SPOILER/` | ранний прототип расследования |
| `avatars/`, `photos/` | картинки персонажей (текущая сборка их пока не использует) |

## Сборка

```sh
cd net3 && python3 build.py && cd ../pc99 && python3 build.py
```

Результат: `pc99/out/index.html` (компьютер с игрой) и `net3/out/index.html` (только игра). Оба файла открываются в браузере.
