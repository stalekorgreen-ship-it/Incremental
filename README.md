# ЛЕНТА.EXE

Инкрементальная игра: ты — рекомендательный алгоритм соцсети. Начинаешь с двух кнопок (▲/▼) и двух чисел (удержание и просмотры) и строишь систему, которая сама понимает интересы людей и находит новые темы.

- `game/index.html` — игра (v8), открывается в браузере. Сборка: `./build.sh`.
- `game/src8/` — исходники v8: `data8.js` (темы, увлечения, эмоции, слова), `sim8.js` (люди, посты, сессии, удержание, деньги), `sys8.js` (правила, словарь, лаборатория, эксперименты, классификация, персонализация, автоисследование, технологии, цели), `ui8.js` (ЛентаОС).
- `game/src/` — прежняя версия с регионами, политикой и финалом с Директором (отключена до отдельного этапа): `./build_legacy.sh` → `game/legacy.html`.
- `MECHANICS.md` — описание механик, `PROGRESS.md` — ход разработки.
- Тесты: `node tools/test8.js`, бот баланса: `node tools/bot8.js 180`.
