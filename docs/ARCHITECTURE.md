# Устройство кода

Чистый JavaScript без библиотек. Каждая сборка — один HTML-файл. Сборщики на Python.

## net5 — проба «живая сеть» (отдельно, в компьютер не вставляется)
`live.js`: алгоритм работает по кругу. Блоки из `net4/core.js` плюс «Память», «Случайные N», «Показ»; у «Склеить» есть «без пары» и ключи с разными названиями («слово = слово 2»); лимит расчёта за круг (не хватает — ленту получает только часть людей). Тем и разметки нет: только слова и реакции на показанное. `refs.js` эталоны для проверок, `ui.js` экран.
Проверки (из `net5`): `python3 build.py && node test.js`; `node try.js` (таблица разных схем); браузер: сервер из `out` на 8768, `node refs_json.js > /tmp/live.json && python3 play.py`.

## net4 — новый конструктор «сырые записи → свои вычисления» (он сейчас внутри компьютера)
Склейка (`build.py`): `data.js`, `core.js`, `refs.js`, `goals.js`, `../net3/fun.js`, `ui.js` (в него вставляются `juice.js`, `art.js`, `pages.js`) внутрь `shell.html`.

| Файл | Роль |
|---|---|
| `data.js` | темы, слова, имена |
| `core.js` | мир со скрытой правдой, 6 сырых таблиц, 7 блоков, нагрузка (секунды пересчёта), деньги и покупки |
| `refs.js` | эталонные схемы: по ним считаются верные ответы. Игроку не показываются |
| `goals.js` | 14 заданий двух глав, 24 вида бесконечных заказов с условиями. `SEED=1`: мир у всех один, пороги подобраны под него |
| `ui.js`, `pages.js`, `shell.html` | поле, таблица блока, задания, заказы, покупки, рубежи; лента, люди, загрузки. Ключ сохранения `lentaos-net4-1` |

Если ответ задания зависит от выбора игрока, эталон должен это учитывать: «Вкусы» считаются на темах самого игрока; в «Первых N» годится любой из равных.

Проверки (из `net4`):
```sh
python3 build.py
node test.js   # блоки, задания, заказы
node bot.js    # темп денег за 30 часов тремя скоростями; бот не думает над схемами
cd out && python3 -m http.server 8767 &   # затем из net4:
node refs_json.js > /tmp/refs.json && python3 play.py /tmp/refs.json   # все задания нажатиями, пишет /tmp/save.json
python3 ui_test.py && python3 orders_test.py && python3 add_test.py
```
Бот и нажатия ставят эталонные схемы: они проверяют, что всё проходимо, а не интересно.


## net3 — лента и конструктор
Порядок склейки (`build.py`): `../ed/topics.js`, `topics2.js`, `packs.js`, `sim.js`, `fun.js`, `ui.js` внутри `shell.html`.

| Файл | Роль |
|---|---|
| `sim.js` | мир: 48 человек, посты, авторы, сигналы, исполнение схемы, визит, деньги, испытания |
| `quests.js` | испытания; после правки `python3 mk.py` вписывает их в `sim.js` между `//Q[` и `//Q]`. Править только здесь |
| `packs.js` | правила восьми пачек: проверяется то, что человек увидел в первых десяти постах |
| `social.js` | вид соцсети: аватары, картинки, посты, профили, сообщества. **Встроен копией в `ui.js`**: `build.py` его не читает |
| `topics2.js` | тексты, комментарии, описания; род задаётся как `<муж|жен>` |
| `ui.js`, `shell.html` | интерфейс; ключ сохранения `lentaos95-packs-2` |
| `fun.js` | измеритель веселья |
| `targets.json` | числовые цели |

### Модель
Одна схема выполняется отдельно для каждого человека. У человека скрытый вкус. Игрок видит только то, что дают источники; полнота зависит от уровня (максимум 8, `cover(L)`). Визит длится, пока хватает терпения; результат — секунды и причины ухода. Если лента дала меньше 12 постов, добавляются случайные.

### Блоки
`all` все посты; `signal` что известно о человеке; `match` совпадение (да/нет); `lists` смешать `+`, склеить `>`, вычесть `−`; `rank` баллы и порядок; `feed` личная лента. У `match`, `lists`, `rank` есть пропускная способность, она прокачивается.

### 30 источников

**Место и техника:** IP-адрес (`ip`), Геометки (`geo`), Дом и работа (`home`), Поездки (`trip`), Устройство (`device`), Связь (`net`)

**Время и ритм:** Время суток (`clock`), День недели (`week`), Длина визита (`visit`), Перерывы (`breaks`), Сезон и погода (`season`)

**Поведение:** Досмотр (`watch`), Пролистывания (`skip`), Повторные просмотры (`rewatch`), Лайки (`likes`), Комментарии (`comments`), Репосты (`reposts`), Сохранённое (`saves`), Не интересно (`nope`), История показов (`history`)

**Люди и сообщества:** Подписки (`subs`), Блокировки (`blocks`), Сообщества (`comm`), Друзья (`friends`), Близость (`close`), Похожие люди (`similar`)

**Намерения и следы:** Поиск (`search`), Куки сайтов (`cookies`), Реклама и переходы (`ads`), Анкета и покупки (`profile`)

Смысл `breaks`: даёт значения только вернувшемуся.

`net3/juice.js` — звуки, праздник, отмена, первые шаги, пропуск; `build.py` вставляет его внутрь `ui.js` вместо `/*JUICE*/`.

## pc99 — компьютер

Интерфейс: `icons.js` (свои значки), `os.js` (окна и действия), `win9x.css` (подключается последним). Игра внутри браузера оформлена сама (`net4/shell.html`).

Оформление сайтов: у каждого из 51 своя вёрстка в `layouts.js` + `layouts.css` (разбирает HTML страниц из `sites.js` и `wildsites.js`: таблицы, новости, списки). `look.js` + `look.css` — старый общий шаблон, из него остались картинки и наклейки. Картинки собраны в `art99.js` скриптом `art99.py` из PNG, нарисованных локально в ComfyUI (SD 1.5 + BiRefNet; исходные PNG в репозиторий не входят). Шрифт Tiny5 (OFL) в `font99.css`.
`os.js` (рабочий стол, окна), `apps.js` (программы), `sites.js` и `wildsites.js` (51 сайт, из них 19 «диких», 3 скрытые страницы), `wild.js` (пиксельная графика), `web.js` (браузер, музыка). Игра из `net4/out/index.html` вставляется в iframe; мост `window.PC`. **Сначала собрать net4.** В SVG data-URI апостроф кодировать как `%27`, иначе пропадает фон.

## Автотестер схем (net3)
`auto.js`: схема как дерево, оценка, случайный поиск, мутации. `refs.js` эталоны, `survey.js` и `holdout.js` проверка на новых мирах, `dyn.js` поиск в живом мире (пишет `dyn_<id>.json`), `full.js` проверка: решение с ветками должно проходить, найденное «в лоб» — нет. `seqfull.js` все 12 испытаний подряд на заработанные деньги.

**Урок:** оценка на замороженном снимке обманывает. В живой игре «История показов» опустошает узкие списки. Пороги брать только из динамической проверки. «В лоб» значит лишь «лучшее, что нашёл поиск».
