# ЛЕНТА.EXE v8 — механики

Игрок — рекомендательный алгоритм. Сначала он ничего не знает о людях и видит только **среднее удержание** и **просмотры**. Постепенно он строит систему, которая сама понимает интересы и находит новые темы.

Сборка: `./build.sh` → `game/index.html`. Исходники — `game/src8/`. Прежняя версия с регионами, политикой и финалом лежит в `game/src/`, собирается `./build_legacy.sh` → `game/legacy.html` (отключена до отдельного этапа).

## Симуляция (game/src8/data8.js, sim8.js)
- **Публикации:**
  - 10 форматов, реальная длина текста по классам (0–50 … >5000 знаков), длительность видео, число фото в галерее;
  - основная тема + любое число вторичных (справочник из 50 тем), 18 эмоций с интенсивностью, структура (18 видов);
  - слова-якоря со словоформами: «машина / машину / машины» → лемма «машина».
- **Люди:** пол, возраст, район, 10–20 увлечений из 80 с силой 1–100 (увлечения связаны группами), 15 поведенческих параметров (время просмотра текста, картинок и видео, склонность лайкать, комментировать, делиться, сохранять, спорить, листать, читать длинное, досматривать, уходить…).
- **Взаимодействие считается для каждой пары «человек — пост»:** интерес к основной и вторичным темам, формат, длина, эмоции и чувствительность к ним, структура, предпочтения по форматам. Из этого получаются время удержания и вероятности лайка, комментария, репоста, сохранения, перехода и ухода. Есть контролируемая случайность.
- **Сессии:** человек заходит, листает ленту пост за постом и уходит, когда кончилось время или после неинтересного поста. Серверы ограничивают, сколько людей онлайн одновременно (100 → 200 → 400 …), остальные не могут зайти.
- **Рост:** приходят по репостам и по сарафанному радио, пока не исчерпан рынок (3 млн).
- **Среднее удержание** — взвешенное по фактическим просмотрам скользящее окно, которое растёт с аудиторией. Одно ▲ лучшего поста: +2,5 с при 100 людях, +0,37 с при 2 500 (tools/test8.js).
- **Деньги:** баннер сбоку платит за секунды, проведённые на платформе. Дольше смотрят → реже уходят → длиннее сессии → больше денег.
- **Журнал просмотров:** платформа записывает, сколько каждый человек смотрел посты с каждым словом-якорем, с поправкой на его обычное время для этого формата. Лаборатория анализирует этот журнал.

## Прогрессия (game/src8/sys8.js) — 47 технологий и сервер
| Этап | Что открывается |
|---|---|
| Ручное управление | ▲/▼, удержание, просмотры |
| Правила | условия: удержание выше/ниже порога или среднего, просмотры; действия: повысить/понизить приоритет, продвигать, закапывать; слоты, И, ИЛИ, третье условие, скорость проверки |
| Словарь | игрок сам прокликивает слова в постах; группы (создать, переименовать, добавить, убрать); условия «слово», «любое слово группы», «все слова группы»; словоформы — отдельная технология |
| Лаборатория | группа отправляется на исследование (60 с). Результаты: категория обнаружена / частично подтверждена (какие слова связаны, какие нет) / недостаточно данных (чего не хватило) / не подтверждена (почему). Улучшения: скорость, слоты, объём данных, точность |
| Эксперименты | правило работает только для случайной половины аудитории (или для интересующихся категорией), сравнение с контрольной группой по t-критерию; при малой выборке — «не доказано». Сравнение лайков и уходов — после открытия метрик |
| Метрики | реакции (лайки, комментарии, репосты, сохранения), уходы и длина сессий, плотность рекламы (больше денег — больше уходов) |
| Пользователи | профиль, текущая активность, история показанных постов с удержанием, что пропустил, что лайкнул, после чего ушёл, следующие посты его ленты |
| Определение интересов | машина оценивает интересы людей по открытым категориям с уверенностью; скорость и точность — улучшениями |
| Персонализация | интересы, похожие пользователи (общие лайки), форматы, прогноз продолжения сессии |
| Автоисследование | машина выбирает человека, берёт слова из постов, на которых он задержался, и отправляет гипотезу в лабораторию. Сначала смешивает темы и ошибается; улучшения: связи слов, чистые гипотезы, редкие интересы, параллельные поиски |
| Автономная система | всё работает само |

22 цели ведут игрока от первого ▲ до автономной системы (окно «Цели»). ОС обновляется: 95 → 98 (правила) → ME (лаборатория) → 2000 (пользователи) → XP (персонализация) → ЛЕНТА.AI (автоисследование).

## Как лаборатория проверяет гипотезу
1. Берёт долю людей (объём данных) и для каждого слова — его время на постах с этим словом относительно его обычного.
2. **Связность:** задерживаются ли одни и те же люди на разных словах. Выделяет связное ядро слов, остальные помечает как «не относятся».
3. **Опознание:** у какой скрытой темы люди с интересом смотрят эти слова заметно дольше остальных (t-статистика). Точность лаборатории — шум в этом шаге: ранние исследования иногда называют тему неверно.
4. **Устойчивость:** та же разница должна повториться в каждой половине журнала.
5. Мало просмотров, людей или слов с данными → «недостаточно данных».
